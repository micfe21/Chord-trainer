🎵 Chord Trainer – Setup Guide

Connect your MIDI keyboard on Apple, Windows, and Android

This guide will help you set up the Chord Trainer app with your MIDI keyboard on any platform. We recommend USB MIDI wherever possible – it's simpler, more reliable, and works immediately.

Quick Start – Universal Steps

  1. Open the app in your browser:
    • Windows: Chrome or Edge
    • Apple (iOS/iPadOS): Web MIDI Browser (from the App Store)
    • Android: Chrome or Edge, with USB MIDI
  2. Connect your keyboard via USB or Bluetooth (see platform-specific steps below).
  3. Tap the MIDI button in the app and select your keyboard from the dropdown.
  4. Tap the orange "Start Audio" button – this is essential to hear sound.
  5. Generate a sequence and start practising!
💡 Important: If you hear no sound, tap "Start Audio" again. This resumes the audio context, which is required on all platforms.

Platform-Specific Guides

🪟 Windows USB MIDI (Recommended)

  1. Plug it in – connect your keyboard to your PC using a data‑sync USB cable (not a charge‑only cable).
  2. Turn it on – power on your keyboard.
  3. Open the app in Chrome or Edge.
  4. Tap the MIDI button – your keyboard should appear in the dropdown (e.g., SMK-37 Pro Midi).
  5. Select it – the status will change to "MIDI connected".
  6. Tap "Start Audio" and play!

🪟 Windows Bluetooth MIDI (Alternative)

Windows does not natively support BLE MIDI. You need two free tools:

  • loopMIDI – creates a virtual MIDI port. Download loopMIDI
  • MIDIberry – receives Bluetooth MIDI and forwards it. MIDIberry on Microsoft Store
  1. Pair your keyboard in Windows Bluetooth settings.
  2. Open loopMIDI and create a new port (e.g., ChordTrainer Port).
  3. Open MIDIberry – enable your keyboard as Input and the loopMIDI port as Output.
  4. In the app, select the loopMIDI port from the MIDI dropdown.
  5. Tap "Start Audio" and play!

🍏 Apple (iOS/iPadOS) Bluetooth MIDI (Recommended)

  1. Download Web MIDI Browser from the App Store (free).
  2. Pair your keyboard in iOS Settings → Bluetooth.
  3. Open the app in Web MIDI Browser.
  4. Tap the MIDI button – your keyboard should appear in the dropdown.
  5. Select it – the status will change to "MIDI connected".
  6. Tap "Start Audio" and play!
📱 Note: Safari and Chrome on iOS do not support Web MIDI. You must use Web MIDI Browser or a similar app.

🍏 Apple (iOS/iPadOS) USB MIDI

  1. Connect your keyboard via USB (use a USB‑C to USB‑B cable, or a Camera Connection Kit for older iPads).
  2. Open the app in Web MIDI Browser.
  3. Tap the MIDI button – your keyboard should appear in the dropdown.
  4. Select it, tap "Start Audio", and play.

🤖 Android USB MIDI (Recommended – Works perfectly)

  1. Connect your keyboard via USB using a USB‑C OTG adapter or cable.
  2. Open the app in Chrome or Edge (both work well).
  3. Grant permission if Android asks for USB access.
  4. Tap the MIDI button – your keyboard should appear in the dropdown (e.g., SMK-37 Pro Midi).
  5. Select it, tap "Start Audio", and play!
✅ USB MIDI on Android is plug‑and‑play. No extra software, no bridge apps, no drivers – just connect and play.
🔊 If sound disappears when you plug in USB:
Android may route audio to the USB port. To fix: swipe down, open "Media Output", and select "Speakers". Or use Lesser AudioSwitch (free) to force audio to phone speakers.

🔧 Troubleshooting

❌ No sound from the app
→ Tap the orange "Start Audio" button. This is required on all platforms.
→ Make sure the Sound toggle is set to "Internal" (not "MIDI Thru").
→ Check your system volume.
❌ Keyboard not appearing in the dropdown
→ Double‑tap the MIDI status text to refresh the device list.
→ Make sure your keyboard is turned on and connected.
→ Try a different USB cable – many cables are charge‑only and don't transfer data.
❌ MIDI connects but keys don't light up
→ Make sure you've generated a sequence (tap "Generate").
→ The app only listens for notes when a chord is displayed.
→ Try tapping "Check" manually.
❌ Web MIDI not supported
→ Windows/Mac: Use Chrome or Edge.
→ iOS: Use Web MIDI Browser from the App Store.
→ Android: Use Chrome or Edge – both support Web MIDI with USB.
❌ On Android, audio disappears when USB is plugged in
→ Android may route audio to the USB port.
→ Swipe down → "Media Output" → select "Speakers".
→ Or install Lesser AudioSwitch to force audio to speakers.
